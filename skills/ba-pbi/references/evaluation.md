# Tình huống kiểm chứng

| Yêu cầu | Kết quả mong đợi |
| --- | --- |
| Thêm một chức năng có mô tả ngắn | Tạo và xuất một PBI trong cùng lượt |
| Chưa chỉ định Round | Chọn đợt phù hợp hoặc lập Round đề xuất |
| Dự án chưa có hồ sơ BA | Khảo sát phần liên quan rồi tự tạo hồ sơ nguồn tối thiểu |
| Chính sách nghiệp vụ chưa rõ | Xuất bản nháp với các điểm còn mở |
| Yêu cầu trùng một PBI | Dùng lại PBI và ID đã có |
| Người dùng chỉ muốn ý tưởng backlog | Trả backlog trong phạm vi yêu cầu |
| File bàn giao đã có và khác nội dung | Giữ file đích và trả đường dẫn preview |
